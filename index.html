下北沢のフォトスタジオ

焚き火のように、
揺らぐ背景
— falo studio

スタジオの名は "falo"。イタリア語で焚き火を意味する。炎がひとときも同じ姿をとどめないように、時の移ろいとともにゆるやかに変わりつづける空間を目指した。

三方に開口を持つ立地を活かし、その中心に一枚の曲面壁を立ち上げた。差し込む自然光が曲面をなぞるたび、陰影は刻々と濃淡を変えていく。

砂丘を思わせるラグ、ドレープを丁寧に操ったカーテン、光を映すステンレスの扉——いずれも、移ろう自然光を敏感に受け止める素材として選んだ。光の変化はそのまま素材の表情となり、空間に奥行きをもたらす。

曲面に沿うレースと遮光のカーテン、そして可動の什器。これらを組み替えれば、背景はそのつど大きく入れ替わる。場を固定しないこの設計は、使い手が自らのイメージのままにスタジオを「編集」することを許容している。

光と時間がもたらす受動的で微細な移ろいと、使い手が加える能動的な編集。ふたつの揺らぎが静かに重なり合うとき、空間は炎の前に腰を下ろしたときのように人をほどいていく。構えがとけ、ふと素のいい表情がこぼれる——その一瞬を写し取るための、背景である。

渋谷の美容室

削ぎ落とした空間に、
残るもの

渋谷という過剰な文脈の中に、意識的に余白を設けた。カットという行為は、素材と向き合い、不要なものを取り除いていく仕事だ。

その場所もまた、余分な主張を排し、施術者と客のあいだに起きることだけが浮かび上がる空間を目指した。白い壁に光が落ち、椅子の脚が床に影を引く——それだけがあれば、十分だと思った。

素材は触れる人の体温を映し、時間とともに育っていく。竣工がゴールではなく、使われることで完成していく空間として設計した。

三軒茶屋のフォトスタジオ

街の温度を、
背景に織り込む

三軒茶屋が持つ、少し古くて親しみやすい空気をスタジオに持ち込んだ。路地に迷い込んだときのような、発見のある空間にしたかった。

写真とは、瞬間を定着させる技術だ。その瞬間が宿る背景を、街の記憶から丁寧に拾い上げた。完璧に整えられた空間ではなく、少し気の抜けた佇まいが、被写体の緊張を解く。

壁の塗りムラ、床の節目、窓の外に見える電線——意図せず入り込む要素が、ときに写真に奥行きを与える。そういった余地を、あえて設計の中に残した。

Installation

素材が
問いになるとき

既成の空間に手を加え、そこで起きる知覚の変容を記録するインスタレーション。建築という枠組みから離れ、素材・光・身体の関係をゼロから問い直した実験的な試みである。

通り過ぎていたはずの場所が、立ち止まらせる場所になる。そのための最小限の操作を探し続けた。

インスタレーションは完成せず、訪れる人の動きや時間の経過とともに変化しつづける。その未完の状態こそが、作品の本質だと考えた。

n!l（ニル）

n!lという名前に、「場所の記憶やクライアントの想いに耳を傾け、そこに潜むあらゆる可能性を掛け合わせることで、まだ見ぬ新しい価値を空間に立ち上げる」という意味を込めました。

n

n  -未知数-

どんな場所にも、まだ誰も解いていない問いが潜んでいます。 土地の記憶。施主の想い。言葉になる前の直感。
それが全部、n です。
私たちの設計は、そのプロジェクトだけの n を見つけることから始まります。

!

!  -可能性をかけ合わせること-

「!」は階乗を表しています。1 × 2 × 3 ×…… 掛け合わせるほど、答えは爆発的に増えていきます。

技術と感性、空間と人、文脈と遊び心…… n を掛け合わせ、 予想のひとつ上を行く「!」をつくる。
それが私たちの仕事です。

l

l  -可能性を煮詰める場所-

仮説を立てる。試す。また問い直す。
正解らしきものに、安易には着地しません。
納得する解が出るまで、何度でも煮詰めるラボ。

n!l

並べて、n!l。

「nil」——ラテン語でゼロを意味します。
前例ゼロ。先入観ゼロ。
毎回ゼロから問い直し、「！」を求めて新しい価値を
組み上げることを目指すデザインコレクティブです。
